# 🍽️ Cafeteria Menu Display

## 📌 Project Overview

The Cafeteria Menu Display is a ServiceNow application developed to simplify cafeteria menu management. It enables administrators to create, publish, and manage daily and weekly menus while allowing employees to view meal options through the Service Portal. The project includes Service Catalog, Reports, UI Actions, and automated workflows. This matches the objectives described in the project document. :contentReference[oaicite:1]{index=1}

---

## ✨ Features

- ServiceNow Studio Application
- Cafeteria Menu Table

- Reports & Dashboard
- UI Action (Mark as Published)

## 🚀 Import Steps

1. Download the Update Set XML.
2. Log in to your ServiceNow Personal Developer Instance.
3. Navigate to **Retrieved Update Sets**.
4. Import the XML file.
5. Preview and Commit the Update Set.
